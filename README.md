# Отчет о летнем внеклассном чтении в веб-формате
## (README.md был сделан в Августе 2026)

это полностью мой веб-сайт со всякими адаптациями и фишками.
сделан чисто, чтобы показать свои навыки и умения.

## языки программирования (использовавшиеся для разработки этого сайта)

* HTML (HyperText Markup Language)
  * типа язык для разметки сайта (не совсем для программирования)
  
* CSS (Cascading Style Sheets)
  * типа язык для описания стилей сайта, тесно связан c HTML

* JavaScript 
  * язык для функциональности сайта
  * старая версия этого сайта была написана на чистом JS
  
* TypeScript
  * улучшенный JavaScript
  * только с большим количеством правил
  * зато стабильнее
  * использовался до того, как сайт переехал к React

* React (библиотека)
  * гораздо удобнее код
  * легче группировать вещи
  * комплекснее
  * сайт недавно переехал на него
